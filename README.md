# 性格计分表

S 活泼型 / C 力量型 / M 完美型 / P 和平型 的四型自评页。优点、缺点各二十行，每行四选一，勾完自动计分。

打开：<https://mingyu92.github.io/personality-score/>

## 能做什么

- 逐行四选一，实时显示四型得分与完成进度
- 滚动时顶部浮条 + 表头吸顶，随时知道选了哪一型、还差几行
- 结果只存在本机浏览器（localStorage），不上传
- 一键导出 JSON、复制文字摘要、打印或存 PDF（打印排成两页 A4）

## 本地使用

直接双击 `index.html` 即可，无需服务器、无外部依赖。

## 文件

- `index.html`：单文件页面，样式、数据、脚本都在里面
- `shot.js`：开发用截图脚本（CDP 驱动 Edge，便于检查布局），日常不用

## 说明

题目文字整理自《性格解析》书籍截图，个别字词或有出入。这是一份倾向统计，不是心理诊断。
